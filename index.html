Digital Pocket Periodic Table of Elements

DPPTE • Chemistry Learning Tool

Digital Pocket Periodic Table of Elements was created by Fernando T. Maruez Jr., a Bachelor of Secondary Education graduate majoring in Science.

Educational Purpose

This application was developed as an educational tool designed to make learning and exploring the periodic table of elements more accessible, interactive, and engaging. It is intended for educational and learning purposes.

How to Use

Explore the Digital Pocket Periodic Table of Elements and use its interactive tools to learn about element groups, periodic trends, atomic structure, temperature states, and chemistry concepts.

  1. Explore the periodic table. The main screen displays all 118 elements arranged by groups and periods. Each element tile shows its symbol, atomic number, name, and atomic mass. Click an element whenever you want to inspect it more closely.
  2. Use the category buttons. Select a category such as metals, nonmetals, metalloids, transition metals, halogens, noble gases, lanthanides, or actinides to highlight the corresponding elements on the table. This makes it easier to recognize patterns and compare related elements.
  3. Try the special classifications. Use the classification buttons for groups such as Coinage Metals, Platinum Group Metals, Chalcogens, Pnictogens, Carbon Group / Tetrels, and Boron Group. These highlights help you study element families that have special names or shared chemical characteristics.
  4. Study periodic trends. Select a trend such as electronegativity, atomic radius, ionization energy, boiling point, density, melting point, electron affinity, or metallicity. The table will visualize the trend so you can observe how the property changes across periods and down groups.
  5. Show trend arrows. Use the trend-arrow controls to display the directional pattern of the selected periodic property. You can also change the displayed direction when the control is available.
  6. Adjust the temperature control. Move the existing temperature slider to explore how temperature affects the displayed state of elements. Depending on an element's melting and boiling points, its symbol can visually indicate whether it is solid, liquid, or gas at the selected temperature.
  7. Open Molecule Simulation. Open the left-side menu and choose Molecule Simulation to experiment with moving particles. Select gas particles or water molecules, then adjust the simulation temperature to observe changes in particle motion and, for water, changes between solid, liquid, and gas states.
  8. View detailed element information. Click any element tile to open its Element Lab profile. The popup organizes information into sections such as overview, atomic structure, physical properties, chemical properties, and periodic trends.
  9. View the atom model. Inside an element's information popup, choose VIEW ATOM to open the interactive atom visualization. Use it as a visual aid for understanding the element's atomic number and electron-shell arrangement.
  10. Read the element story. Choose ABOUT ELEMENT inside the element popup to flip to the information side. This section provides historical context, discovery information when available, and a short "Did You Know?" fact for the selected element.
  11. Take the Chemistry Quiz. Open the left-side menu and select Quiz Is It! to use the existing quiz system. Choose a difficulty and question count, answer each question, review the feedback, and check your final score and results.
  12. Use Clear All when needed. If several categories, classifications, or trend highlights are active, use Clear All to remove the current highlighting and return the periodic table to its normal view.
  13. Use the left-side menu. The ☰ button opens the DPPTE navigation drawer. From there you can access Quiz Is It!, Molecule Simulation, and future chemistry-learning tools such as Build a Compound, Reaction Builder, and Bohr Model.
  14. About the app. Use the ? button in the lower-left corner to read information about DPPTE, its creator, its educational purpose, and the project's development and copyright notice.
💡 Learning tip: Try selecting an element first, then compare its group and period with nearby elements. Next, test a periodic trend and adjust the temperature. Combining these tools makes it easier to see how the periodic table connects element properties, atomic structure, and states of matter.
